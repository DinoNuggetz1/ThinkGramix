# ThinkGramix
A LLM designed to predict speech and eventually generate its own

In order to run V1 you must be on Linux or run it in an Linux subsystem
You may add more data to the data sets on but know it will affect performance but there is a limit in which it will not add any benefit to accuracy especially for the 3 gram model. To Run the 5 gram model you must download the chosen data set, for the five gram model a larger data set is recommended.
